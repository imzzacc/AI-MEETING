## 需要解决的具体质量问题

1. **MySQL m3-correct**：问题要求解释分析InnoDB幻读时为何区分普通一致性读和锁定读。回答已经列出快照与范围锁机制，助手建议COVERED。两次新模型仍判PARTIAL，并补出“锁定读可能因锁范围不足出现幻读”等给定资料没有建立的因果解释。评分是否完整需人审，但资料不支持的解释是明确问题。
2. **缓存 c3-incorrect**：简洁修正版本轮通过，追加提示后却又把问题中的“热点键失效后大量并发请求回源”当作用户回答。运行时原文校验能拒绝该证据；单次通过不能证明问题永久消失。
3. **volatile新增部分正确样例**：回答说明可见性，坦承不知道原子性。助手建议PARTIAL，模型在atomicity评分点判NOT_OBSERVED。需要明确评分点是否只评原子性；这可能是建议标签或评分点粒度问题，不应为通过检查直接修改标签。
