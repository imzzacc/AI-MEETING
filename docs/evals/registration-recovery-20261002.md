# 注册与登录矛盾提示修复

故障表现：注册提示用户名已存在，登录却提示用户不存在。对用户指定账号只查询记录是否存在，没有读取密码：当前业务库没有记录，而旧注册可用性接口返回false。旧实现直接把布隆过滤器命中当作已注册，因此缓存残留或概率误判会永久阻止本来可用的名字。另一个提示缺陷是密码不匹配也被说成用户不存在。

修复改为在用户名锁内查询MySQL实际记录，再用数据库唯一键兜底并发冲突。可用性API保留旧契约：true=可注册。锁忙提示稍后重试；登录匹配失败提示“用户名或密码错误”。注册过程不再读写布隆过滤器，不清空共享缓存，也没有修改用户账号或密码。

- 用刚创建且从未登录的专用合成账号制造“数据库无记录、布隆缓存有记录”的测试状态。旧版本确实错误返回不可注册；新版本浏览器注册成功。
- 真实浏览器验证错误密码的准确提示、正确密码登录、受保护面试页及刷新恢复、重复注册拒绝；数据库大小写比较规则对应的名称可用性检查通过。最后再次只读检查用户指定名称，确认可注册。没有用用户密码做测试。
