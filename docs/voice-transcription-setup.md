# 语音回答配置

语音回答的链路是：浏览器麦克风 → 后端 WebSocket（`/api/xunzhi/v1/xunfei/audio-to-text/{userId}`）→ 讯飞“实时语音转写大模型” → 回答框。

## 配置

在讯飞开放平台控制台进入应用，确认已经开通“实时语音转写大模型”并且有额度，然后把该应用的三项凭证配到后端环境变量里：

```dotenv
XUNFEI_APP_ID=
XUNFEI_API_KEY=
XUNFEI_API_SECRET=
```

- Docker Compose 会读取 `.env`；直接 `java -jar` 启动时不会自动读取，需要自己导入环境变量；
- 面试工作流（出题、评分）的凭证和这里无关，配好了工作流不代表语音可用；
- `XUNFEI_RTA_API_KEY` 不能替代这三项。

## 使用和排查

浏览器只在 `localhost` 或 HTTPS 页面里允许使用麦克风。点击“开始语音回答”后，页面会先显示“正在连接语音识别”，等服务端确认转写已经开始才会开始采集，这时显示“正在倾听中”。停止后，已经识别的文字保留在输入框里，可以继续编辑。

常见提示：

| 提示 | 原因 |
| --- | --- |
| 语音识别服务尚未配置 | 运行中的后端进程没有拿到上面三项环境变量 |
| 语音识别服务不可用，请检查权限及额度 | 应用没有开通实时语音转写大模型，或者额度用完了 |
| 麦克风权限被拒绝 | 在浏览器地址栏的网站权限里允许麦克风 |
| 语音转写连接失败或已中断 | 10 秒内没有收到服务端确认，或者连接中途断开 |
